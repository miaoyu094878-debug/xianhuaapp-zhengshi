# 设备风险与换机判断指南

> 用途：判断「运营过程中哪些行为会让手机报废（必须换机）」，以及如何自检设备是否已被平台标记。
> 适用：iPhone 运营海外社媒（TikTok / Instagram / YouTube 等）的独立设备方案。

---

## 一、先分清两种封禁

| 类型 | 严重程度 | 处理方式 |
|---|---|---|
| **账号被封**（Account Ban） | 中 | 换号可继续，设备还能用 |
| **设备被标记 / 设备封禁**（Device Ban） | **致命** | 这台机注册任何新号都会被关联或秒封，等于报废 |

**只有第二种才需要换手机。** 但大量高危行为会从「账号封」逐步升级为「设备封」。

---

## 二、高危行为（按危害程度分级）

### 🔴 一级：直接毁设备

| 行为 | 后果 |
|---|---|
| **账号被封后，同一台机立刻注册新号** | 封号记录绑定设备指纹，新号一出生即被关联，连环封 |
| **一台机频繁切换多个账号** | 设备被标记为「营销设备 / 矩阵机」 |
| **使用群控、改机软件、模拟器、越狱插件** | 直接判定作弊，永久标记 |
| **把买来的号 / 来源不明的号登到设备上** | 号自带风险记录，污染设备指纹 |

### 🟠 二级：加速设备被标记

| 行为 | 后果 |
|---|---|
| 同一 IP 挂多个号 | IP 被污染，设备连带 |
| 多台手机连同一个 Wi-Fi 运营 | 通过局域网特征关联设备 |
| 多个号用同一手机号 / 邮箱 / 支付方式 | 账号图谱串联 |
| **VPN 掉线漏出真实中国 IP** | 最致命，前后矛盾信号 |
| 设备语言中文 + IP 美国 + 时区错乱 | 矛盾指纹，风控加权 |

### 🟡 三级：账号级风险（可能升级为设备风险）

| 行为 | 后果 |
|---|---|
| 批量操作：同一时间大量点赞 / 关注 / 评论 | 被判为机器行为 |
| 搬运 / 侵权 / 违规内容 | 账号封禁，多次后牵连设备 |
| 短时间反复抹机重置 | 异常行为，也会被记录 |
| 新号一上来就大量发视频 | 新号权重低，容易触发审核 |

---

## 三、设备是否已「废」的自检法

### 标准测试流程

```
① 抹机（Erase All Content and Settings）
② 换一条全新的、独立的 IP
③ 新的 Apple ID
④ 注册新号
⑤ 正常养号 3–5 天，发 3–5 条视频
```

### 结果判断

| 结果 | 结论 |
|---|---|
| 能进流量池（300+ 播放） | ✅ 设备没问题，继续用 |
| 单条 0 播放 | 🟡 先怀疑 IP / 内容 / 养号节奏 |
| **连续 2–3 个新号都是 0 播放或秒封** | 🔴 **设备已被标记，考虑换机** |

**关键：至少用 2 个不同新号 + 2 条不同 IP 验证，避免把「IP 问题」误判成「设备报废」。**

---

## 四、日常规避清单

### 铁律三条

```
✅ 一台设备 = 一个号
✅ 一个号 = 一条独享 IP
✅ 封号后不在原设备重注册
```

### 完整清单

- [ ] 一台设备只登一个运营号
- [ ] 一个号绑定一条独享 IP，不共享、不轮换
- [ ] 账号被封后，不在原设备原地重注册（换机，或间隔足够久 + 彻底抹机）
- [ ] 绝不使用群控 / 改机 / 模拟器 / 越狱插件
- [ ] 语言 = English、地区 = United States、时区 = IP 所在地，三者一致
- [ ] 新号先养 3–5 天，再开始发内容
- [ ] 发内容节奏平缓，不批量、不集中时间点
- [ ] 不连公共 Wi-Fi；多台设备不共用同一 Wi-Fi
- [ ] 不在设备上登录来源不明的账号
- [ ] 不频繁抹机重置

## 五、设备健康自检表（可复制使用）

```
设备：__________   序列号：__________

[ ] 仅登录 1 个运营账号
[ ] IP 独享，且与设备时区一致
[ ] 语言 English / 地区 US / 时区 = IP 所在城市
[ ] 未安装群控、改机、模拟器类工具
[ ] 未登录来源不明的账号
[ ] 封号后未在原机重注册
[ ] 新号养号满 3 天以上才发内容
[ ] 账号未出现连续 0 播放

评估结果：
全部勾选 → 设备健康
出现 1 项未勾选 → 立即纠正，观察 1 周
连续 2–3 个新号 0 播放/秒封 → 设备疑似被标记，准备换机
```

## 六、快速结论

**真正让手机报废的只有一件事：设备指纹被平台标记（Device Ban）。**

最典型的触发路径：
1. **账号被封 → 同一台机立刻注册新号**（第一杀手）
2. 一台机频繁切换多个账号
3. 使用群控 / 改机 / 模拟器
4. 登录买来的、来源不明的账号

判断方法：**抹机 + 新 IP + 新 Apple ID + 新号**，若连续 2–3 个号都是 0 播放或秒封 → 设备已废。

日常守住三条铁律即可长期使用：**一台机一个号、一个号一条独享 IP、封号不在原机重注册。**
